## 📖 About The Project

**10KICKS** is a state-of-the-art front-end web application designed to deliver a premium sneaker shopping experience. It features fluid animations, glassmorphism UI elements, and a sophisticated dark-theme minimalist design. 

Explore curated collections from top global brands—Nike, Adidas, Puma, and Converse. Seamlessly add items to your cart, save favorites to a wishlist, and experience a streamlined mock checkout flow that feels completely native.

<br/>

> **Note:** This project is a frontend prototype demonstrating advanced UI/UX principles, DOM manipulation, and vanilla state management without relying on heavy frameworks.

---

## ✨ Key Features

- 🎨 **Dynamic & Premium UI**: Fluid CSS animations, glassmorphism cards, and a striking dark-theme aesthetic designed to maximize user engagement.
- 🏷️ **Brand-Specific Categories**: Specialized filtering and exploration for industry-leading brands (Nike, Adidas, Puma, Converse).
- 🔍 **Immersive Product Details**: Rich product preview pages featuring image carousels, dynamic pricing, size selection, and immediate add-to-cart functionality.
- 🛒 **Slide-out Panels**: Non-intrusive, interactive side panels for both Cart and Wishlist to keep users in the flow of browsing.
- 💳 **Comprehensive Checkout**: A fully realized mock checkout experience with multi-step validation, delivery forms, and multiple payment methods (Card, UPI, Net Banking, COD).
- 📱 **Mobile-First Responsiveness**: Flawless execution across all devices with an intuitive hamburger menu and adaptive grid layouts.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

All you need is a modern web browser (Chrome, Firefox, Safari, Edge). No Node.js or complex build pipelines are required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/IrfanCodesBTW/10kicks.git
   ```
2. **Navigate to the directory**
   ```bash
   cd 10kicks
   ```
3. **Launch the application**
   - Simply double-click `index.html` to open it in your browser.
   - *Alternatively, for the best experience, use an extension like **Live Server** in VS Code to serve the files.*
